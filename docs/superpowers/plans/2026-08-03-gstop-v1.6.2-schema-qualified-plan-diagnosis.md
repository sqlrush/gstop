# gstop v1.6.2 Schema-Qualified Plan Diagnosis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make gstop identify the exact schema behind an unqualified EXPLAIN relation, suppress misleading index advice for maintenance SQL, prove the scenario 601 fault/recovery behavior against og5, and locally deploy gstop v1.6.2.

**Architecture:** Safe current-plan collection will prefer verbose EXPLAIN and retain a compatibility fallback. Before catalog diagnosis, a lexical SQL relation extractor will enrich only uniquely provable plan relations with their explicit schema. The catalog and index-analysis path remains fail-closed when evidence is ambiguous. Maintenance statements remain diagnosable but carry a neutral, not-applicable index assessment.

**Tech Stack:** Go 1.26, openGauss connector, text EXPLAIN parser, tcell TUI, Go `testing`, Docker container `og5`.

## Global Constraints

- Never infer a schema from `search_path`; bind only explicit schema-qualified SQL relations or schema-qualified plan evidence.
- Never bind when one SQL statement contains multiple compatible schema candidates.
- Ignore relation-looking text inside SQL comments, string literals, quoted string bodies, and dollar-quoted bodies.
- Historical real plans remain eligible for display, while catalog diagnosis uses the selected catalog plan plus the SQL text belonging to that candidate.
- Suggested DDL is display-only and must never be executed by gstop.
- `ANALYZE` and `VACUUM` scans show index advice as `不适用` and never produce CREATE INDEX candidates.
- The target version is exactly `v1.6.2`.
- `/Users/sqlrush/gstop` is the authoritative gstop runtime source for this change and is not a Git work tree.
- Do not overwrite `/Users/sqlrush/gstop/gsbench-local/bin/gstop`; it is a wrapper containing local configuration behavior.
- Deploy only by backing up and atomically replacing `/Users/sqlrush/gstop/gsbench-local/bin/gstop.real` after automated and real og5 acceptance succeeds.
- Do not stop or alter a user-owned gstop/gsbench process unless it is conclusively identified as this acceptance run.
