# gstop v1.6.1 Current Index Advice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep historical execution plans visible while making gstop's index advice reflect the current EXPLAIN and current index catalog, then release and locally deploy gstop v1.6.1.

**Architecture:** The detail pipeline will maintain independent display-plan and catalog-plan selections. Display quality remains unchanged, while catalog selection prefers current runtime/current EXPLAIN over history. Catalog analysis merges only unambiguous display-plan index references into current table accesses, validates unqualified scan-local identifiers against `pg_attribute`, and assesses them against the current index catalog.

**Tech Stack:** Go 1.26, openGauss connector, text EXPLAIN parser, tcell TUI, Go `testing`.

## Global Constraints

- Historical real plans remain the display winner over ordinary EXPLAIN.
- Catalog/index advice uses current runtime or current EXPLAIN when available.
- No suggested DDL is executed; it remains display-only.
- Unqualified identifiers are accepted only from direct scan predicates and only after exact current-catalog validation.
- The target runtime version is exactly `v1.6.1`.
- `/Users/sqlrush/gstop` is not a Git work tree; source commit steps are intentionally omitted.
- Do not overwrite `/Users/sqlrush/gstop/gsbench-local/bin/gstop`; it is the configuration wrapper.
- Back up and replace only `/Users/sqlrush/gstop/gsbench-local/bin/gstop.real` after verification.

func catalogPlanRank(candidate planCandidate) int {

        return 0
    }
}
